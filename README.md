# Tripleten - Around The U.S.

O **Around The U.S.** é uma página desenvolvida em React que permite aos usuários gerenciar uma galeria de fotos e personalizar seu perfil. O projeto simula uma rede social focada em viagens, com autenticação de usuários para privacidade e segurança dos dados.

## 🚀 Funcionalidades

- **Autenticação e registro:** login, criação de conta e logout. A sessão é mantida utilizando JWT armazenado no Local Storage.
- **Rotas protegidas:** controle de acesso em rotas privadas. Usuários não autenticados são redirecionados automaticamente para a tela de login.
- **Gerenciamento de perfil:** edição de nome, ocupação e atualização de foto de avatar.
- **Galeria:** adição e remoção de cards de fotos, com funcionalidade de curtir as fotos.
- **Feedback visual:** estados de carregamento durante as requisições à API e validação de formulários.

## 🛠️ Tecnologias e Técnicas Usadas

- **React.js:** biblioteca principal para construção da interface em componentes reutilizáveis.
- **Vite:** ferramenta de compilação para estruturar e rodar o projeto de forma otimizada.
- **React Router DOM:** biblioteca para roteamento do projeto sem precisar recarregar o navegador.
- **Integração com API REST:** Comunicação assíncrona para registro, login, e manipulação dos dados da galeria.
- **Programação orientada a objetos:** reuso de lógica de validação de formulários via classe JavaScript.
- **CSS Avançado:** metodologia BEM e design responsivo, adaptando-se a diferentes tamanhos de tela, com no mínimo 320px de largura.
